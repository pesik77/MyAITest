# Chemické prvky – procvičování

Jednoduchá statická webová aplikace na procvičování prvků skupin **1.A – 4.A**
periodické tabulky (značka, český a latinský název, básničky na zapamatování).

## Režimy
- **Přehled** – tabulka prvků po skupinách s básničkami
- **Kartičky** – otáčecí kartičky (přední strana: značka / český / latinský název)
- **Kvíz** – libovolná kombinace skupin a typů otázek; výběr ze 4 možností (klávesy 1–4) nebo psaní odpovědi
- **Pořadí** – seřazení prvků ve skupině shora dolů

## Spuštění
Stačí otevřít `index.html` v prohlížeči – vše je v jednom souboru, nic se nestahuje
z internetu, takže funguje i offline.

Při nasazení na web (např. GitHub Pages) se navíc zaregistruje service worker,
aplikace se uloží do mezipaměti a jde ji „nainstalovat“ na telefon jako PWA.
